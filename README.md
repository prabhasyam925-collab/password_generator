# 🔐 Password Generator in C++

## 📌 Project Description

The **Password Generator** is a simple C++ console-based mini project that generates a random password based on the length entered by the user.

The generated password can contain:

- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

This project is useful for beginners to understand **strings, loops, random number generation, and user input in C++**.

---

## ✨ Features

- 🔐 Generates random passwords
- 🔢 User can choose the password length
- 🔠 Includes uppercase letters
- 🔡 Includes lowercase letters
- 🔢 Includes numbers
- 🔣 Includes special characters
- ⚡ Simple and easy-to-use console interface

---

## 🛠️ Technologies Used

- **C++**
- `iostream` – Input and output
- `cstdlib` – Random number generation
- `ctime` – Used to seed the random number generator
